# UI flows: операції обладнання та фото

## Створення прийому або видачі

**Route and action:** `POST /devices`; створення запису обладнання.

**Role and preconditions:** локальний користувач; є хоча б одна модель обладнання.

1. Відкрити вкладку «Обладнання».
2. Ввести текст, вибрати модель, дату та, за потреби, номер договору зі слешем.
3. Вибрати «Прийом» або «Видача».
4. Натиснути «Зберегти запис».

**Expected result:** у таблиці відображаються договір, операція та інші дані без дубля; експорт містить ці ж поля.

**Negative/guard case:** номер договору довший за 20 символів не зберігається, сервер повертає помилку валідації.

**Future Playwright notes:** `#device-crud`, `[name="contract_number"]`, `[name="operation_type"]`, кнопка з текстом «Зберегти запис».

## Додавання з OCR/AI та відкриття фото

**Route and action:** `POST /devices`, `POST /devices/{device}/source-image/open`.

**Role and preconditions:** вибране зображення, виконано OCR або AI-розпізнавання, виділено текст у результаті.

1. Натиснути правою кнопкою на виділеному тексті.
2. Вибрати один із пунктів додавання в БД.
3. Зберегти запис на вкладці «Обладнання».
4. У рядку запису натиснути «Відкрити файл».

**Expected result:** створений запис зберігає шлях вибраного фото; Windows Explorer відкривається з виділеним файлом.

**Negative/guard case:** після видалення чи переміщення фото кнопка показує повідомлення про недоступність файла та не видаляє запис.

**Future Playwright notes:** `.context-action-menu [data-ocr-action="normal"]`, `[data-open-source-image]`.
