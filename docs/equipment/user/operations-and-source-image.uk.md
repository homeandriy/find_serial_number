# Прийом і видача обладнання

1. Відкрийте вкладку «Обладнання».
2. Введіть серійний номер або текст, виберіть модель і дату.
3. За потреби введіть номер договору. Можна використовувати слеш, наприклад `123/45`.
4. Виберіть «Прийом» або «Видача».
5. Натисніть «Зберегти запис».

Якщо текст отримано з OCR або AI, виділіть його, натисніть праву кнопку миші та виберіть «Додати в БД» або «Додати в БД неформатовано». Фото буде прив’язано до запису автоматично.

У таблиці натисніть «Відкрити файл», щоб Windows відкрив Провідник і виділив вихідне фото. Якщо фото було переміщено чи видалено, програма повідомить про це; сам запис обладнання залишиться збереженим.
